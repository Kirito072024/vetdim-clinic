# E2E-сценарії

Перевіряють зібраний сайт у справжньому браузері (headless).

```bash
# 1. Запустити API і production-збірку клієнта
npm run dev:server                       # з кореня репозиторію
cd client && npm run build && npx vite preview --port 4173

# 2. Запустити сценарії
cd e2e && npm install && npm run all
```

Змінні: `BASE_URL` (за замовчуванням `http://localhost:4173`), `BROWSER_PATH` (шлях до Edge/Chrome).

| Скрипт | Що перевіряє |
|---|---|
| `booking-flow.js` | Фільтр лікарів → сторінка лікаря → 4 кроки запису → помилки валідації → успішний запис → 404 |
| `checks.js` | Бургер-меню, тема, пошук, 404 лікаря, форма контактів, падіння API, клавіатура |
| `overflow.js` | Відсутність горизонтальної прокрутки на 360 / 768 / 1280 px для всіх маршрутів |
