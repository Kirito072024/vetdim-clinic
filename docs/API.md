# REST API «ВетДім»

Сервер: **Node.js + Express 5**, код у [`server/`](../server). Дані зберігаються в JSON-файлах (`server/data/`).
Базова адреса локально: `http://localhost:3001/api`.

## Ендпоінти

| Метод | Шлях | Опис | Успіх | Помилки |
|---|---|---|---|---|
| GET | `/health` | Перевірка роботи сервера | 200 | — |
| GET | `/doctors?specialty=&q=` | Список лікарів, фільтр за спеціалізацією та пошук за ім'ям | 200 | — |
| GET | `/doctors/:id` | Лікар за id | 200 | 404 |
| GET | `/doctors/:id/slots?date=YYYY-MM-DD` | Слоти лікаря на дату: `[{ time, available }]` | 200 | 400, 404 |
| GET | `/services?category=` | Список послуг, фільтр за категорією | 200 | — |
| GET | `/services/:id` | Послуга за id | 200 | 404 |
| GET | `/appointments?doctorId=&date=` | Список записів | 200 | — |
| GET | `/appointments/:id` | Запис за id | 200 | 404 |
| POST | `/appointments` | **Створити запис** | 201 | 400, 409 |
| PUT | `/appointments/:id` | Оновити (перенести) запис | 200 | 400, 404, 409 |
| DELETE | `/appointments/:id` | Скасувати запис | 204 | 404 |
| POST | `/feedback` | Повідомлення з форми «Контакти» | 201 | 400 |

## Приклад: створення запису

```http
POST /api/appointments
Content-Type: application/json

{
  "serviceId": 2,
  "doctorId": 1,
  "date": "2026-11-16",
  "time": "10:00",
  "ownerName": "Олена",
  "phone": "+38 (067) 123-45-67",
  "email": "olena@example.com",
  "petName": "Барсик",
  "petType": "cat",
  "petAge": 3,
  "comment": "Щеплення від сказу"
}
```

Відповідь `201 Created`:

```json
{
  "id": 1,
  "number": 1001,
  "status": "confirmed",
  "createdAt": "2026-11-11T12:00:00.000Z",
  "serviceId": 2,
  "doctorId": 1,
  "date": "2026-11-16",
  "time": "10:00",
  "phone": "+380671234567",
  "...": "..."
}
```

## Формат помилок

```json
{
  "error": "Перевірте правильність заповнення форми",
  "fields": {
    "phone": "Введіть номер у форматі +380XXXXXXXXX",
    "petName": "Як звати вашого улюбленця?"
  }
}
```

| Статус | Коли |
|---|---|
| 400 | Помилка валідації або некоректний JSON; `fields` містить помилки по полях |
| 404 | Ресурс або маршрут не знайдено |
| 409 | Обраний слот уже зайнятий |
| 413 | Тіло запиту більше 20 КБ |
| 500 | Внутрішня помилка (деталі лише в логах сервера) |

## Серверна валідація

| Поле | Правило |
|---|---|
| `serviceId`, `doctorId` | Мають існувати; лікар має надавати обрану послугу |
| `date` | `YYYY-MM-DD`, не в минулому, не далі ніж 30 днів, робочий день лікаря |
| `time` | Один зі слотів 09:00–17:30 з кроком 30 хв, ще не минув, не зайнятий (інакше 409) |
| `ownerName` | 2–60 символів, лише літери, пробіл, апостроф, дефіс |
| `phone` | Після видалення пробілів/дужок/дефісів — `+380XXXXXXXXX` |
| `email` | Необов'язковий; якщо є — коректний формат |
| `petName` | Обов'язкове, до 40 символів |
| `petType` | `cat` \| `dog` \| `other` |
| `petAge` | Необов'язковий, 0–30 |
| `comment` | До 500 символів |

## Змінні середовища

| Змінна | За замовчуванням | Призначення |
|---|---|---|
| `PORT` | `3001` | Порт сервера |
| `CORS_ORIGIN` | `*` | Дозволені адреси фронтенду через кому |
| `DATA_DIR` | `server/data` | Папка з JSON-даними |
| `DEMO_BUSY` | `true` | Імітувати записи, зроблені телефоном (частина слотів зайнята) |
