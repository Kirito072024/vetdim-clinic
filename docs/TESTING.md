## 4. Доступність (a11y)

- [x] Контраст тексту ≥ 4.5 : 1 у світлій і темній темах (перевірено скриптом, див. `DESIGN.md`)
- [x] Посилання «Перейти до вмісту» (skip link)
- [x] Семантичні `header`, `nav`, `main`, `footer`, `article`, `aside`, `address`
- [x] Усі поля мають `<label>`; помилки пов'язані з полями через `aria-describedby`, поле з помилкою має `aria-invalid`
- [x] Кнопки-перемикачі (`chip`, `slot`, `date`) мають `aria-pressed`
- [x] Бургер-меню: `aria-expanded`, `aria-controls`, закриття клавішею Escape з поверненням фокусу
- [x] Після переходу між кроками форми фокус переводиться на заголовок кроку
- [x] Динамічні зміни озвучуються (`aria-live` для лічильника результатів і підсумку запису, `role="alert"` для помилок)
- [x] Видимий `:focus-visible`, цілі натискання ≥ 44 × 44 px
- [x] `prefers-reduced-motion` вимикає анімації
- [x] Декоративні SVG мають `aria-hidden="true"`, інформативні зображення — `alt`

## 7. Знайдені та виправлені дефекти

| Дефект | Як знайдено | Виправлення |
|---|---|---|
| Сторінка падала при переході між маршрутами (`destroy is not a function`) | Автоматичний сценарій у браузері | `useEffect(() => window.scrollTo(0, 0))` неявно повертав результат `scrollTo` (у нових браузерах це Promise), а React сприймав його як функцію очищення. Тіло ефекту взято у фігурні дужки |
| Нумерація «1. Головна 2.» у хлібних крихтах | Скриншот 360 px | `list-style: none` для `.breadcrumbs ol` |
| Бейдж спеціалізації розтягувався на всю ширину картки | Скриншот 1280 px | `align-self: flex-start` |
| Великий відступ на внутрішніх сторінках на десктопі | Скриншот 1280 px | Медіазапит більше не перебиває `.section--tight` |
| `hidden` не ховав опції форми | Тест сценарію запису | `[hidden] { display: none !important }` |
