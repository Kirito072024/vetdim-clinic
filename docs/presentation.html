  • Сайти клінік незручні на телефоні

ПР 4–7 · Клієнт

HTML → CSS → JS → React

  • HTML5: семантика, 0 помилок W3C
  • CSS3: токени, Grid, Flexbox, clamp(), темна тема
  • JS: ES-модулі, Fetch, валідація, debounce
  • React 19 + Vite: Router, lazy-сторінки, хуки useFetch, useTheme

Цікавий баг

useEffect(() => window.scrollTo(0, 0)) «ламав» React: у нових браузерах scrollTo повертає Promise, а React сприймав його як функцію очищення.

Знайдено e2e-тестом, виправлено фігурними дужками.
